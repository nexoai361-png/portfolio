# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and Phosphor icons.

## Features

- **VS Code Dark+ Theme**: Dark mode styling with VS Code-inspired colors
- **Phosphor Icons**: Clean, consistent iconography using Phosphor Icons
- **Cabin Font**: Modern typography with system font fallbacks
- **SVG Smooth Animations**: Smooth entrance animations for all elements
- **Responsive Design**: Mobile-first layout with adaptive breakpoints
- **Data Visualizations**: Bar charts, progress bars, and stat cards
- **Professional Images**: Unsplash-sourced profile and project images

## Technologies Used

- HTML5
- CSS3 (with custom properties, flexbox, grid)
- Phosphor Icons (via CDN)
- Google Fonts (Cabin)

## Sections

- **Hero**: Introduction and call-to-action
- **About**: Professional profile and experience
- **Skills**: Technical skills with icons
- **Projects**: Project showcase with images
- **Graphs**: Data visualizations (bar charts, progress bars)
- **Stats**: Key metrics display
- **Contact**: Contact information and links

## Responsive Breakpoints

- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: 480px - 767px
- Small Mobile: 0 - 479px

## Setup

Simply open `index.html` in any modern web browser. No build tools or server required.
